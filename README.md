# Lukenya Ridge

Website for **Lukenya Ridge** by Comex Homes, premium plots on Nairobi's Mombasa Road growth corridor.

Live: https://www.lukenyaridge.com

Built with Next.js (pages router), same structure as the Nyayo View Suites site.

## Edit content
- Project facts shown in the "You are viewing" strip: `components/data.js`
- Images: `public/images/`
- Brochure: `public/Lukenya-Ridge-Catalogue.pdf`

## Run locally
```
npm install
npm run dev
```
